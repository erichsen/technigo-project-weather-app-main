## Weather App
A simple weather web app built with HTML, CSS and JavaScript using the OpenWeather API.

## Features
- Displays current weather for Norrköping
- Shows temperature and weather description
- Presents sunrise and sunset times in a readable format
- Displays a 4‑day weather forecast
- Clean, responsive layout inspired by an editorial design style

## Technologies used
- HTML
- CSS
- JavaScript (Fetch API)
- OpenWeather API
